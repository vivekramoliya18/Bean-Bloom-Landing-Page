# Bean & Bloom Cafe — Figma Landing Page Design ☕

## Project Overview

Bean & Bloom Cafe is a fictional café brand concept created to showcase café offerings, highlight best-selling drinks, and communicate the brand's identity through a modern landing page design.

## Target Audience

- Coffee and café lovers
- College students
- Young professionals
- Customers looking for a cozy café experience

## Design Features

- Desktop landing page design
- Header with logo and navigation
- Hero section with café imagery
- Menu and category highlights
- Bestseller product cards
- Café story/about section
- Customer testimonials
- Newsletter subscription section
- Footer with navigation and social links
- Consistent typography, colors, and spacing

## Design Tools

- Figma
- Auto Layout
- Reusable Components
- Color and Typography Styles

## Design System

### Color Palette

| Color Name | Hex Code |
|---|---|
| Warm Cream | `#FFF8F0` |
| Coffee Brown | `#4A2F27` |
| Caramel | `#C58B55` |
| Soft Pink | `#EBC7C4` |
| Light Beige | `#F5EBDD` |
| Dark Text | `#30211D` |

### Typography

- **Playfair Display** — Headings
- **DM Sans** — Body text, navigation, and buttons
